PHONE BEHAVIOUR
---------------
1. First time phone.html opens, the repaired phone is visible and locked.
2. Passcode: 0521
3. Once unlocked, the home screen appears.
4. Clicking an app opens that app in the phone screen.
5. App Back returns to the previous phone screen.
6. Messages -> person -> Back returns to the message list.
7. Messages -> person -> Back -> Back returns to Home.
8. The bottom dock only belongs to the Home screen.
9. The PHONE/HIDE side button controls the entire phone.
10. Clicking HIDE is what locks the phone.
11. Clicking PHONE again shows the lock screen; enter 0521 again.
12. Pressing Back inside an app NEVER locks the phone.
